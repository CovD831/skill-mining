# skill-mining

从一个项目或一段时间的开发史里，提取可复用、可移植给他人的 skill（操作指南）。

**只做提取层**：挖掘、判据、通用化、证据取舍；结构化入库交给任意现成的 skill creator，质检交给等价工具（格式 `npx skill-lint`、安全 `npx claude-skill-guard scan`、质量 evals A/B——工具或网络缺席则标注「未质检」）。产出的候选包按通用指南格式起草——既是 skill creator 的输入，也是 creator 缺席时的成品草稿。

## 什么时候用

- 用户说「提取 skill / 提炼 skill / 沉淀方法论 / skill 盘点」。
- 周期性盘点：项目新增的实践是否值得固化成指南。

## 流水线定位

上游=项目语料；本 skill=Skill Creator 的**前置采集层**；下游=Creator 结构化入库 → 质检（格式/安全）→ 质量校验（evals A/B）。每一环缺席都能独立工作。

## 提案台账（MINING-LOG.md）

技能目录下的 `MINING-LOG.md` 是本技能的跨期台账，每轮挖掘从读它开始，落盘后回写一行：
`日期 | 语料窗 | 提案数 | 落盘数 | 用户圈定项 | 备注`
**提案数与落盘数永远分列**——报告里写了多少条新 skill，不等于磁盘上真的有。

## 安装

把 `SKILL.md` 拷进你的 agent 技能目录（如 `~/.claude/skills/skill-mining/`，或你所用平台的等价位置）。纯 prompt，零依赖，无脚本、无附属文件（`MINING-LOG.md` 由首次运行自动创建）。

## 验证

一次对照尝试（同一素材、同模型，样本 n=1，欢迎用你自己的语料复测）：带技能的代理收敛出 7 条带排序的候选（按 复发次数 × 可移植性 × 证据强度）+ Top3 标准候选包；无技能基线产出 40 条无法直接使用的平铺清单。素材为某项目 2007 行单日工作日志。
